# AxoHile

Minecraft Java 1.21.4 client mod built with Fabric.

## Build

Requires Java 21 and Gradle 8.10.2.

```bash
gradle build
```

The JAR is generated in `build/libs/`.

## Source layout

- `AxoHileClient.java` — Fabric client entrypoint.
- `Hacks.java` — intentionally empty placeholder reserved for owner-written code.
